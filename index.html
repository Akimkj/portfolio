HTML (Hypertext Markup Language) é a linguagem de marcação padrão para páginas da Web. Minha experiência com essa linguagem foi por meio de estudos com a platarforma "Curso em Vídeo", desenvolvendo desafios e projetos que na época, pra mim, eram complexos e me fizeram ter um nível avançado nessa linguagem atualmente.

CSS (Cascading Style Sheets) é a linguagem que usamos para estilizar um documento HTML. Minha experiência com essa linguagem é similar ao HTML, uma vez que no ínicio dos meus estudos quanto a programação, me dediquei a dominar essas tecnologias. Atualmente, meu nível de CSS é intermédiario.

JavaScript é uma linguagem leve e de tipagem dinâmica, mais conhecida como a linguagem de script para páginas Web. Boa parte da minha experiência com essa linguagem veio por meio da imersão Dev com a Alura e da platarforma do "Curso em Vídeo". Apesar disso, atualmente, meu nível no JavaScript é iniciante, pois ainda estou começando meus estudos acerca da linguagem supracitada.
